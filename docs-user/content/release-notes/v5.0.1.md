# v5.0.1 發行說明

**發布日期**：2025 年 12 月 2 日

## 🖥️ 使用者介面

- 即時預覽失敗時，原本不會顯示任何錯誤訊息，現在會顯示失敗原因，告知使用者哪個字元無法轉換成點字。
- 主視窗的「說明」選單裡增加了「使用手冊」，可開啟線上使用手冊網頁。

## 🔧 技術改進

- **修正記憶體洩漏**：解決了在重複建立點字轉換器時可能發生的記憶體洩漏問題，提升了長時間執行的穩定性。
- **修正單元測試不穩定**：解決了 `ExternalBrailleConverterTests` 在並行執行時因暫存檔名衝突而導致的測試失敗問題。
- **Txt2Brl 工具更新**：新增 `--result` 與 `--error` 命令列參數，允許指定結果與錯誤日誌的輸出路徑，改善了與主程式的整合性。
