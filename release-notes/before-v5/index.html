    v5.0 之前的版本變更紀錄#

    v4.2.4 (2024-01-12)#

    • 修正：印表機名稱沒有自動保存於設定檔，導致每次列印時都要選擇印表機。
    • 改進：使用介面的字型從原本的 新細明體 改為 微軟正黑體。
    • 升級第三方套件。

    v4.2.3 (2023-08-29)#

    • AppConfig.ini 的 [Braille] 區段增加一個參數：

      UseUpperPositionForNumbers = false ; 數字一律使用上位點。v4.2.1 (2023-9-1) 之後開始支援此選項。 把參數值改為 true 即可在轉點字時，令數字一律使用上位點。

    • 新增中文標點符號：《 》轉譯為 (126-126 345-345) ，〈 〉轉譯為 (126 345)。 注意事項：你如果有在 AppConfig.ini 中把 《 》 重新對應為 <書名號>，則會優先採用你的設定。

    • 更新相依套件：

      • “Microsoft.VisualStudio.SlowCheetah” Version=“4.0.50”
      • “MinVer” Version=“4.3.0”
      • “Serilog” Version=“3.0.1”

    v4.2.0 (2022-10-10)#

    • 從 .NET 6 升級至 .NET 7。

    v4.1.4 (2022-3-18)#

    • 放寬試用版的限制： 從這個版本開始，試用期間可以處理最多 5 頁的文字，列印的頁數限制也是 5 頁。 一旦超過試用期，則只能處理 1 頁的文字。

    v4.1.0 (2022-2-7)#

    • 重要！開啟雙視檔案時，不再支援 v1.0 時期的 .BTX 二進位格式。
    • 技術變更：升級至 .NET 6.0。

    v4.0.0-beta (2021-1-24)#

    • 技術變更：升級至 .NET 5.0。

    v3.18.0 (2019-12-3)#

    • 列印對話窗增加參數：「每一方點字的列印寬度」，預設值為 24。 此參數會用來計算每個明眼字的字寬（會影響字距），因為列印時，明眼字和點字 必須對齊。
    • 列印對話窗增加參數：「每一列明眼字的高度」，預設值為 40.0975。 此參數可用來調整每一列明眼字所佔據紙張的高度（即字高加上列距）。

    v3.16.0 (2019-08-26)#

    • 修正問題 #4：在雙視編輯視窗修改點字之後，開啟［檢視 > 明眼字］顯示的 內容卻是舊的。
    • 更新第三方函式庫至新版本。

    v3.15.9 (2019-01-23)#

    • 更新第三方函式庫至新版本。
    • 調整版本授權檢查規則。

    v3.15.7 (2018-12-26)#

    • 修正：按住 Ctrl+X 或者 Ctrl+Delete 不放，快速產生一連串剪下或刪除的操作， 會造成 “索引超出範圍” 的錯誤。

    v3.15.6 (2018-12-21)#

    • 增加符號：△ （1246 2345 點） 點字規則：前後均空方。
    • 增加符號：↔ （246 25 25 135 點） 點字規則：前後均空方。
    • 雙視編輯視窗現在可以按 Ctrl+Shift+V 把剪貼簿的點字貼上至行尾（或者在儲存 格上點滑鼠右鍵，也可以在選單中找到此功能）。
    • 列印明眼字時，現在可以指定列印份數。（列印點字的功能則仍只能列印一份）

    v3.15.3 (2018-12-17)#

    • 雙視編輯視窗的插入文字視窗，現在也可以將標籤套用至選取文字。
    • 雙視編輯時，滑鼠左鍵點擊兩下後，即可修改字(即F4功能)。編輯頁標題時也是。
    • 編輯頁標題時，現在也可以使用剪貼簿的功能，包括：複製（Ctrl+C）、剪下 （Ctrl+X）、貼上（Ctrl+V）。但由於每一列頁標題都是關聯至正文的特定位置， 所以不可複製和貼上多列，而只能複製同一列中的文字。

    v3.15.2 (2018-12-14)#

    • 明眼字編輯視窗增加搜尋和取代功能。 搜尋：Ctrl+F （可一次顯示所有符合的字串） 取代：Ctrl+H
    • 開啟明眼字檔案時，現在一律使用 UTF-8 編碼。
    • 製作新的安裝程式。使用此新版安裝程式便可以透過雙擊 .brx 檔案來直接開啟 易點雙視。
    • 修改授權註冊方式，加入試用期限 30 天。

    v3.14.6 (2018-12-13)#

    • 應用程式核心元件更新。 注意：必須更新，否則後續版本在更新時可能會因為無法處理子目錄檔案而失敗。

    v3.14.4 (2018-12-11)#

    • 修正：在雙視編輯視窗按 WinKey+D 回到 Windows 桌面，或將視窗縮到最小，再 切回雙視編輯視窗時，垂直卷軸的位置會跑到最頂端。修正後，按 WinKey+D 時已 經會記住卷軸位置。
    • 明眼字編輯視窗增加「復原」與「重做」功能，快捷鍵分別是 Ctrl+Z 和 Ctrl+Y。
    • 明眼字編輯視窗左方增加行號（列號），游標加粗並以藍色顯示。
    • 明眼字編輯視窗的 <> 標籤文字改以加粗的標楷體顯示，以便和一般文字區分。

    v3.14.0 (2018-11-28)#

    • 在明眼字編輯視窗中，若先選取了一些文字，然後點擊成對的標籤或符號按鈕 （例如私名號、書名號、引號等等），以往會以標籤文字或符號取代原先選取 的文字，現在則會以成對的標籤符號將選取的文字包住。 示範影片：https://youtu.be/hfz-OWbCOSQ
    • 雙視編輯視窗增加了「全選」功能。 操作方式：按 Ctrl+A 或在儲存格上面點滑鼠右鍵，然後點［全選］。
    • [技術規格] .NET Framework 版本從 4.7.1 改為 4.7.2。

    v3.13.1 (2018-10-12)#

    • 修正：自訂片語（phrase.phf）如果是定義一個中文字的注音，會沒有作用。

    v3.13.0 (2018-10-11)#

    • .NET Framework 版本從 4.5.2 升級至 4.7.1。
    • 修正：只要明眼字有包含 “電波”，轉點字時就會出現應用程式錯誤（異常結束）。

    v3.12.3 (2018-08-10)#

    • 修正：版本更新時，若本機的版本號碼包含非數字的字串，會造成無法更新。
    • 修正：版本更新之後不用再重新註冊。
    • 為主程式補上圖示（桌面的捷徑才會有貓頭鷹圖示）。
    • 更新安裝程式。

    v3.12.0 (2018-07-11)#

    • 修正：［插入一串文字］視窗的工具列的［箭頭］按鈕沒作用。
    • 加入軟體註冊機制。若沒有註冊，將無法列印和輸出雙視文件。

    v3.11.43 (2018-06-23)#

    • 新增：把雙視文件另存為 HTML 網頁的功能。 操作方式：從雙視編輯視窗的主選單點「檔案 > 匯出為網頁」。

    • 修正：轉點字時，標點符號的前面一律不加空方。 由於「標點符號」很多，為了避免有特例，所以在 AppConfig.ini 裡面的 [Braille] 區塊增加兩個參數來控制：

      NoSpaceAfterTheseCharacters = 「『“‘… ;這些字元的右邊一律不自動加空方。 NoSpaceBeforeTheseCharacters = ，。？！：；、…」』”’） ;這些字元的左邊一律不自動加空方。

    • 修改：拿掉雙視編輯視窗的「匯出文字檔」功能，因為此功能並沒有辦法完美達成最初設計的目的：希望匯出的文字檔可重複轉成點字。原因在於後來增加的一些控制標籤在轉點字的過程中就會丟棄，並沒有保存下來。所以即使能匯出文字檔，也無法保證能夠在轉出一模一樣的點字。使用者若想要查看明眼字，可以透過［檢視 > 明眼字］功能。

    v3.11.40 (2018-06-22)#

    • 新增：<URL> 區塊。用於輸入網址。
    • 新增：<分隔線>。
    • 新增：<無數符>。包在此區塊內的數字都不會自動加數符。
    • 改進：自動斷行時，加入更多檢查，以確保： (1) 左括號和上引號不出現於行尾。 (2) 右括號和下引號不出現於行首。
    • 修正：數學區塊的刪節號應是三個第 3 點。
    • 修正：數學區塊的打勾、打圈、打叉符號： <數學>（√）。</數學> <數學>x，</數學> <數學>o。</數學> <數學>√。</數學>
    • 修正：雙視編輯模式下，按住 Ctrl+Del 不放來快速刪除點字時，常常出現找不到點字物件的情形。

    v3.11.34 (2018-06-21)#

    • 新增：雙視編輯的［插入一串文字］功能增加［原書頁碼］與［刪除文 字］按鈕。
    • 新增：主選單的［說明］底下增加［版本修改歷史］。
    • 修正：雙視編輯時，「插入一串文字」視窗裡，若點［分數］按鈕，下方會立刻出現紅色訊息提示有錯誤，但沒有顯示任何錯誤訊息。
    • 修改：使用原書頁碼標籤 <P> 時，如果沒有指定任何頁碼，例如： <P></P> 則表示不要原書頁碼（清空原書頁碼）。
    • 修改：<刪> 區塊裡面的文字一律不加空方，也不加數符。

    v3.11.32 (2018-06-20)#

    • 修正數學點字，以滿足下列規則： (a) 數學區塊的問號跟一般文字的問號是不同的點字。 (b) 算式裡，只有第一個數字要加數符，但第一個數字左邊若是左括弧，則不加數符。 (c) 算式之間都不空方，例如 “（ ）x5” 的乘號和 5 之間不加空方。 (d) 問號跟刪節號之間要空方。
    • 修正：數學區塊中的編號項目【 】裡面不應自動加空方。
    • 修改：全形水波符號 ‘～’ 的點字改為兩方的 (2 5) 點（跟短破折號一様）。

    v3.11.28 (2018-06-14)#

    • 增加：<特殊引號一> 和 <特殊引號二> 標籤。這兩個標籤都會產生一對中文全形的單引號：「」，但是它們的下引號所對應的點字並不相同。
    • 修正：全形引號裡面，上引號「的右邊不加空方，下引號」的左邊不加空方。
    • 修正：英文全形單引號和雙引號裡面不加額外空方。
    • 改善：因殘留多個 <上位點> 標籤，導致列印時找不到原書頁碼。
    • 修正：雙視編輯的［插入一串文字］功能，如果插入了很長的文字，轉成點字之後超過兩行，網格上面只會顯示兩行的內容，而少了其他行（只是顯示的問題，文件內容是正確的）。
    • 其他操作介面的小改進，例如雙視編輯的網格背景顏色加深，以便其他對話窗顯示時更明顯。

    v3.11.24 (2018-06-13)#

    • 修正：全形方括號【】裡面有數字時，括號後面的數字的數符也被刪除了。現在修正為只有方括號裡面的數字才會移除數符。
    • 改善：如果原書頁碼加了多餘的 <上位點> 標籤，預覽列印時會略過。

    v3.11.23 (2018-06-12)#

    • 增加：［比例］按鈕，會固定產生字串 “1:1”。主要是為了避免使用者在輸入比例時，使用了中文全形的冒號。
    • 修正：數學區塊的括弧符號的點字。 測試案例：<數學>（1cm寬）</數學>。
    • 修正：數學區塊中的全形冒號、上引號、下引號的點字。
    • 修正：在某些情況下，執行［段落重整］時會造成程式當掉。
    • 改善：如果原書頁碼加了多餘的 <上位點> 標籤，預覽列印時會略過。

    v3.11.19 (2018-06-09)#

    • 新增：雙視編輯模式的「插入一串文字」視窗裡面增加數學符號列。
    • 修正：數學區塊 <數學> 中的圓括弧（）中間若有數字，數字左邊不加空方。
    • 修正：數學點字規則中有關括弧、逗號、分號及句號的處理。
    • 改進：執行［段落重整］時，程式會自動偵測可能造成無窮迴圈的狀況。若判定該次段落重整操作可能造成無窮迴圈，程式將中止操作，並提示使用者如何復原該次操作。

    v3.11.14 (2018-06-08)#

    • 修正：雙視編輯模式的尋找文字功能有時會出錯。

    v3.11.13 (2018-06-07)#

    • 改進：雙視編輯視窗中，若當前所選取的那行是新的頁標題的開始位置，那麼狀態列就會顯示頁標題的內容。此外，編輯網格的左邊行號也會標示 “標” 來代表那行開始有一個新的頁標題。頁標題編輯視窗的狀態列則會顯示目前選取的頁標題所對應至雙視文件中的行號。
    • 修正：表格的中間與右邊界垂直線轉出來的點字不正確。

    v3.11.11 (2018-06-06)#

    • 新增：「表格橫槓 (10方)」按鈕。此功能可用來插入 10 個表格橫線符號。其中一個可能的用途式做為數學的直式算式的橫線。
    • 新增：雙視編輯模式增加一個功能：「移除選取範圍的數符」。快速鍵是 Ctrl+Alt+3。
    • 改進：插入表格時，現在可以讓使用者自行指定要幾列、幾欄，以及每 一欄裡面要有幾個空方；而且明眼字和雙視編輯模式都可以插入表格。
    • 改進：修改一些破音字的預設讀音，包括：礦、怎、不、液….等等。
    • 改進：「可復原的操作」視窗現在多了一個核取方塊，讓使用者可以自行決定是否總是顯示這個視窗。
    • 改進：頁標題編輯視窗開啟和儲存時，會檢查並刪除空的頁標題。
    • 改進：頁標題編輯視窗增加更多編輯功能。主要是刪除一行和複製貼上。
