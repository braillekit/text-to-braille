    版本編號說明#

    「易點雙視」採用語意化版本編號系統：

    • 主版本號（Major）：當有不相容的 API 變更或重大功能改變
    • 次版本號（Minor）：當新增功能但保持向後相容
    • 修訂號（Patch）：當進行向後相容的問題修正

    例如：5.0.0 表示主版本 5、次版本 0、修訂版 0。
