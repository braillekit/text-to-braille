# 點字字型對應表

## 概述

`BrailleFontTbl.txt` 是每個點字碼所對應的點字字型碼，格式為：

```text
點字碼=點字字型碼
```

字碼皆為 16 進位數字。點字字型碼所對應的字型是 `simbrl.ttf` 的字型。

參考：點字字型\點字字型-字元表.gif

---
