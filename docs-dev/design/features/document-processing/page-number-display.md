# 頁次的表現

## 明眼字表示法

在編輯明眼字時，原書頁次以單行的 `<P></P>` 標記來表現。

### 範例

原書第 39 頁，則輸入：

```xml
<P>39</P>
```

## 點字轉換結果

在轉換點字時，碰到 `<P></P>` 標記，則轉換成整列的直線，最右邊標上頁次，如下：

```text
::::::::::::::::::::39
```

> **註**: 連續多個英文的冒號（二、五點）印出來看起來就是連續的一條長直線。

### 特殊情況：整頁為圖

如果某頁整頁都是圖，則可以輸入：

```xml
<P>40（圖）</P>
```

印出來的結果會是：

```text
::::::::::::::::::::40（圖）
```

## 點字書頁次

點字書的頁次則是動態計算，並列印於每頁的右下角。
