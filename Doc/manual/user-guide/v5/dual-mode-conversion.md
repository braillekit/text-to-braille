# 雙模式點字轉換

從 v5.0 版本開始，EasyBrailleEdit 引入了「雙模式點字轉換」架構，提供更穩定且彈性的點字轉換服務。

## 什麼是雙模式轉換？

本系統現在支援兩種點字轉換模式：

1. **內建模式 (In-Process Mode)**：
    - **預設模式**。
    - 轉換核心直接整合在應用程式中。
    - **優點**：效能較佳，轉換速度快，記憶體使用更有效率。

2. **外部工具模式 (External Tool Mode)**：
    - 使用獨立的 `Txt2Brl.exe` 程式進行轉換。
    - 這是舊版本的運作方式，保留作為備援方案。
    - **優點**：獨立運作，若內建模式發生未預期的問題，可切換回此模式以確保工作不中斷。

## 如何切換模式？

您可以透過修改設定檔來切換轉換模式。

1. 關閉 EasyBrailleEdit 應用程式。
2. 在應用程式安裝目錄中找到 `AppConfig.ini` 檔案。
3. 使用記事本開啟該檔案。
4. 找到 `[Braille]` 區段下的 `UseInProcessConversion` 設定：

    ```ini
    [Braille]
    ; 設定為 true 使用內建模式（預設），設定為 false 使用外部工具模式
    UseInProcessConversion=true
    ```

    - **啟用內建模式**：設定為 `true`
    - **啟用外部工具模式**：設定為 `false`

5. 儲存檔案並重新啟動應用程式。

## 常見問題

### 為什麼需要兩種模式？

雖然內建模式經過嚴格測試且效能更好，但為了確保在任何情況下使用者都能順利完成工作，我們保留了舊版的外部工具模式作為「安全網」。如果您在使用內建模式時遇到任何異常（例如轉換結果不正確或程式不穩定），可以暫時切換回外部工具模式，並回報問題給開發團隊。

### 如何確認目前使用哪種模式？

目前介面上不會直接顯示當前模式，但您可以查看 `AppConfig.ini` 的設定值。未來版本可能會在「關於」或「設定」視窗中顯示此資訊。
