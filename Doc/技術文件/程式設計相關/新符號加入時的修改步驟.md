# 新符號加入時的修改步驟

本文件說明如何為 EasyBrailleEdit 點字轉換系統添加新的符號或字元。

## 概要

點字轉換系統採用**策略模式（Strategy Pattern）**，由以下核心元件組成：

- **XML 點字符號表** - 定義符號與點字碼的對應關係
- **BrailleTable 類別** - 載入並管理 XML 符號表
- **Converter 類別** - 實作符號轉換邏輯
- **BrailleProcessor** - 協調所有轉換器，統一處理點字轉換

## 基本步驟

### 1. 編輯點字符號表 (XML)

符號表位於：`BrailleToolkit/Data/`

現有的符號表：

| 符號表檔案 | 描述 | 對應的 Converter |
|-----------|------|-----------------|
| `TwChineseBrailleTable.xml` | 台灣中文點字（注音、標點符號） | `TwChineseCharConverter` |
| `EnglishUebBrailleTable.xml` | 英文 UEB 點字（字母、縮寫、標點） | `EnglishUebConverter` |
| `MathBrailleTable.xml` | 數學符號 | `MathConverter` |
| `PhoneticBrailleTable.xml` | 音標符號 | `PhoneticConverter` |
| `TableBrailleTable.xml` | 表格符號 | `TableConverter` |
| `CoordinateBrailleTable.xml` | 座標符號 | `CoordinateConverter` |
| `UrlBrailleTable.xml` | URL 符號 | `UrlConverter` |

#### XML 格式

```xml
<?xml version="1.0" encoding="utf-8"?>
<Symbols>
  <!-- 基本符號 -->
  <symbol text="符號" dots="點位" type="類型" description="說明" />
  
  <!-- 多方點字 -->
  <symbol text="符號" dots="點位1 點位2" type="類型" description="說明" />
  
  <!-- 具特殊屬性 -->
  <symbol text="ㄓ" dots="1" type="Phonetic" mono="true" />
  <symbol text="ㄧㄚ" dots="23456" type="Phonetic" joined="true" />
  <symbol text="△" dots="1246 2345" type="Misc" rule="SpaceAtBothEnds" />
</Symbols>
```

#### 屬性說明

| 屬性 | 必填 | 說明 | 範例 |
|------|------|------|------|
| `text` | ✓ | 原始符號（明眼字） | `"○"`, `"＋"`, `"ㄅ"` |
| `dots` | ✓ | 點位表示，1-6 代表對應的點 | `"135"`, `"246 135"` |
| `type` | ✓ | 符號類型 | `"Phonetic"`, `"Punctuation"`, `"Math"`, `"Misc"` |
| `description` | | 符號說明 | `"加號"`, `"音界號"` |
| `mono` | | 單音字（中文） | `"true"` |
| `joined` | | 結合韻（中文） | `"true"` |
| `rule` | | 特殊規則 | `"SpaceAtBothEnds"` |

#### 點位格式

- **單方點字**：`"135"` 表示點 1、3、5
- **多方點字**：`"25 25"` 表示兩個點字方，各為點 2、5
- **空方**：`" "` （一個空白字元）

> **重要**: 專案的 Build Action 屬性應設定為 **Embedded Resource**。

### 2. 建立點字符號表類別

如果是新增至現有符號表，**跳過此步驟**。

如果要建立新的符號類別（例如：化學符號），則需建立對應的類別：

```csharp
// BrailleToolkit/Data/ChemBrailleTable.cs
using System.Reflection;

namespace BrailleToolkit.Data
{
    /// <summary>
    /// 化學符號點字表。
    /// </summary>
    public sealed class ChemBrailleTable : XmlBrailleTable
    {
        private static ChemBrailleTable? m_Instance = null;

        /// <summary>
        /// 建構函式。
        /// </summary>
        private ChemBrailleTable()
            : base()
        {
        }

        /// <summary>
        /// 傳回 singleton 物件，並載入資源。
        /// </summary>
        public static ChemBrailleTable GetInstance()
        {
            if (m_Instance == null)
            {
                m_Instance = new ChemBrailleTable();
                m_Instance.LoadFromResource();
            }
            return m_Instance;
        }

        /// <summary>
        /// Creates a new instance of ChemBrailleTable.
        /// </summary>
        public static ChemBrailleTable CreateInstance()
        {
            var instance = new ChemBrailleTable();
            instance.LoadFromResource();
            return instance;
        }
    }
}
```

> **模式**: 繼承自 `XmlBrailleTable`，實作 Singleton 模式，並提供 `CreateInstance()` 方法。

### 3. 建立轉換器類別 (Converter)

如果要建立新的轉換器（例如：化學符號轉換器）：

```csharp
// BrailleToolkit/Converters/ChemConverter.cs
using BrailleToolkit.Data;

namespace BrailleToolkit.Converters
{
    public sealed class ChemConverter : WordConverter
    {
        private ChemBrailleTable m_Table;

        /// <summary>
        /// 建構函式。
        /// </summary>
        public ChemConverter()
            : base()
        {
            m_Table = ChemBrailleTable.CreateInstance();
        }

        /// <summary>
        /// 從堆疊中讀取字元，並轉成點字。
        /// </summary>
        public override List<BrailleWord>? Convert(Stack<char> charStack, ContextTagManager context)
        {
            if (charStack.Count < 1)
                throw new ArgumentException("傳入空的字元堆疊!");

            List<BrailleWord>? brWordList = null;
            char currentChar = charStack.Peek();
            
            // 嘗試從符號表中查詢
            string? brailleCode = m_Table[currentChar.ToString()];
            
            if (brailleCode != null)
            {
                var brWord = new BrailleWord(currentChar.ToString(), brailleCode);
                brWord.ContextNames = context.ContextNames;
                
                brWordList = new List<BrailleWord>();
                brWordList.Add(brWord);
                
                charStack.Pop(); // 從堆疊移除已處理的字元
            }
            
            return brWordList;
        }

        internal override BrailleTableBase BrailleTable
        {
            get { return m_Table; }
        }
    }
}
```

> **關鍵**: 
> - 繼承自 `WordConverter` 或實作 `IWordConverter`
> - 實作 `Convert(Stack<char>, ContextTagManager)` 方法
> - 成功轉換後**必須**從 `charStack` 移除已處理的字元
> - 若無法轉換則返回 `null`，保留字元在堆疊中

### 7. 處理多字元符號（如需要）

如果新符號包含多個字元（例如：`"【1】"`, `"ㄨㄛ"`，`"O₂"`），需在對應的 Converter 的 `Convert` 方法中撰寫特殊處理邏輯。

#### 範例：處理括號數字

```csharp
public override List<BrailleWord>? Convert(Stack<char> charStack, ContextTagManager context)
{
    // 檢查是否為 【數字】 格式
    if (charStack.Count >= 3)
    {
        char[] chars = charStack.Take(3).ToArray();
        if (chars[2] == '【' && char.IsDigit(chars[1]) && chars[0] == '】')
        {
            string text = new string(chars.Reverse().ToArray());
            string? brailleCode = m_Table[text];
            
            if (brailleCode != null)
            {
                // 移除已處理的字元
                charStack.Pop();
                charStack.Pop();
                charStack.Pop();
                
                var brWord = new BrailleWord(text, brailleCode);
                return new List<BrailleWord> { brWord };
            }
        }
    }
    
    // 單字元處理...
}
```

> **注意**: `Stack<char>` 是反向的，最上方是最後一個字元。

## 常見問題

### Q: 如何確定點位編碼？

**A**: 點位對應關係如下：

```
點 1 = Bit 0 = 0x01 = 十進位 1
點 2 = Bit 1 = 0x02 = 十進位 2
點 3 = Bit 2 = 0x04 = 十進位 4
點 4 = Bit 3 = 0x08 = 十進位 8
點 5 = Bit 4 = 0x10 = 十進位 16
點 6 = Bit 5 = 0x20 = 十進位 32
```

例如：點位 "2456" = 2 + 8 + 16 + 32 = 58 = 0x3A

### Q: XML 載入失敗怎麼辦？

**A**: 
1. 確認 XML 檔案的 Build Action 設為 **Embedded Resource**
2. 確認 XML 格式正確（使用 `validate_braille_xml.py` 驗證）
3. 確認 `LoadFromResource()` 方法正確載入資源

### Q: 符號無法轉換？

**A**: 檢查以下項目：
1. XML 中是否已定義該符號
2. Converter 是否已在 `BrailleProcessor` 中註冊
3. `ConvertWord` 方法中的轉換優先順序
4. 若需情境標籤，確認標籤是否啟用

### Q: 如何處理破音字？

**A**: 中文破音字的處理邏輯在 `TwChineseCharConverter` 中，使用 `ZhuyinReverseConverter` 取得注音碼，並利用 `ZhuyinPhraseTable` 進行智慧型詞彙分析。
