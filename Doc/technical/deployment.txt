部署程序

1. 確保 ChangeLog.txt 已經編寫完成，而且所有改變皆已 commit，並且合併至 main branch。

2. 在 main branch 建立 git tag，例如："4.1.0"，並且推送至 git server。

   指令範例：git tag 4.1.0
   
   Note: tag 名稱只能是版本號碼。如果在版本號碼前面加上 "v，例如 "v4.1.0"，將導致 Flubu
         建置專案時忽略該 tag。

3. 建置方案，若成功，檔案會輸出至以下資料夾：

   Output\EasyBrailleEdit\Release\<.NET-target>\

   注意：`Txt2Brl.exe` 及其依賴項會自動複製到上述目錄中。
   
   檢查上述資料夾中的主程式 EXE 和 DLL 檔案的版本是否與 Step 2 的 tag 一致。
   
   注意：`AppConfig.ini` 會在程式首次執行時自動產生，部署時不需包含此檔案，除非需要預設特定設定。

4. 把 Step 3 產生的應用程式檔案手動揀選並複製到另一個專用來更新的 GitHub 專案資料夾：
   https://github.com/braillekit/text-to-braille-updates/tree/main/Files
   
5. 到上一個步驟提到的 Files 資料夾下修改 _update.txt 的內容，確保版號正確。

6. 在本機測試能否自動更新。

7.如果需要打包安裝程式，使用 InnoSetup 製作安裝程式：Setup\InnoSetup\iss。
