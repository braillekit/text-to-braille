# 易點雙視版本發布說明

## v5.0.0-alpha (2025-11-23)

### 作業環境需求

- **作業系統**: Windows 10（僅支援 64 位元電腦）
- **執行環境**: .NET 10

### 安裝程序

1. **確保已經安裝了所有最新的 Windows Updates**

2. **下載並安裝 .NET 10 SDK**
   
   以瀏覽器開啟以下網址：
   ```
   https://dotnet.microsoft.com/zh-tw/download/dotnet/10.0
   ```
   
   在頁面上找到 SDK 10.x.x，裡面有 Arm64、x64、和 x86 三種版本，請點選 x64 下載連結，即可下載 .NET SDK 安裝程式。下載後，直接執行安裝程式。

3. **安裝「易點雙視」**
   
   執行安裝程式 `setup.exe` 即可開始安裝。  
   預設的應用程式安裝路徑為 `C:\EasyBrailleEdit5`。
